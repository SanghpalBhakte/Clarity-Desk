# Glossary

Words students see in Clarity Desk, and what each one means. One word per idea.

**Today**
The home screen. It says what is happening now and next, lets the student mark it in one gesture, shows what is due, then gets out of the way.

**Late**
A task whose due date has passed and is not done.
_Avoid_: overdue, slipped (the recovery line may say a task "slipped" as a friendly phrase, but the label is Late)

**Due**
Tasks with a date coming up that are not done yet.

**Now**
The class happening at this moment. The only thing on Today shown as a card.

**Next**
The first class still to come today.

**Free**
A gap between two classes today. Never shown in red or pink.
_Avoid_: break

**Mark**
Record attendance for one class: Present, Absent, or another choice under More.
_Avoid_: attend (as a verb for the action)

**Theme**
A colour set the student picks in Settings → Look. Each theme looks clearly different, not only in its colours.
_Avoid_: accent, palette, appearance

**Light / Dark / Auto**
Whether the screen is light or dark, or follows the phone. Separate from the theme: every theme works in both.
_Avoid_: theme, mode names like Paper Slate or Midnight Ink

**Backup**
A file the student saves that holds everything on their desk, so it can be put back later or on another phone. For a student who is not signed in, it is the only copy outside this phone.
_Avoid_: export, JSON
