# Today C2, shared look and tab bar: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Today, the shared look (type, palettes, Auto dark) and the phone tab bar and laptop sidebar so the live app matches the C2 mockup on phone and laptop, with tested swipe and hold gestures.

**Architecture:** Everything stays in the existing files (`app.js`, `style.css`, `index.html`, `404.html`, `sw.js`); no build step and no new runtime files except Lexend woff2. New pure helpers (labels, strip layout) live in one marked block in `app.js` so node tests can load them. One new CSS token layer goes **last** in `style.css`. Marks go only through the existing attendance functions.

**Tech Stack:** Vanilla JS, CSS, node `tests/verify_*.mjs` (pure functions, harness as in `tests/verify_today_calm.mjs`), Playwright `tests/*.spec.ts` against `node tests/serve.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-20-today-c2-design.md`. Mock: `docs/superpowers/specs/assets/2026-11-20-today-c2-mock.html` (open it locally; it is the visual target). Mock gesture script: `docs/superpowers/specs/assets/2026-11-20-mock-gesture-tests.mjs`.

## Global Constraints

- One branch per task, `claude/today-c2-<n>-<slug>`, one PR per task; CI `Tests` green before merge; never push to main; ship only when the user says "ship".
- Commit subjects in plain words for students (they become Dev Notes); `chore:` for test/docs-only.
- 12-hour AM/PM everywhere. Never rename a `cos_*` key or change a stored shape. New key allowed: `cos_strip_labels` only.
- Free tiers only; no new dependencies. Lexend is self-hosted (woff2 in repo), never loaded from Google Fonts at runtime.
- Status colours never change per palette: present `--ok`, absent `--bad`, late `--bad` with icon. On the strip, status is shown as coloured label + 6 px dot, **never** as a block fill. Only "Free" uses the palette accent fill.
- Palette display names (ids unchanged): `terracotta` → **Highlighter**, `rose` → **Old Campus** (default), `lavender` → **Last Bench**, `apricot` → **Lo-fi**.

## Review Focus

1. **Minute re-render mid-gesture.** Today re-renders every minute. An open swipe, an open row, a hold in progress, or an open sheet must survive it: the open row id and sheet are saved UI state like `railMoreOpenKey`. Test in Task 5.
2. **Strange timetables.** One class only (6 h pad), three batches at the same time ("3 labs"), a class ending after 9 PM, a single-word long name ("Workshop", "Seminar"), two subjects deriving the same initials (Computer Networks and Compiler Notes → both "CN"). Expected: no cut label, no repeated label, every class in the rows. Tests in Task 4.
3. **Old saved settings.** `cos_theme` holding a legacy value, `paper-slate`, `midnight-ink` or garbage; `cos_accent` missing or unknown. Expected: a saved light or dark choice wins, unknown values become `auto`, and accent falls back to `rose`. Test in Task 2.
4. **Restore an old backup** without `cos_strip_labels`: labels fall back to automatic; nothing throws. Test in Task 8.
5. **Swipe on iPhone Safari tab** (not installed): a right swipe that starts within 20 px of the left screen edge is the browser's back gesture. Rows ignore pointerdown with `clientX < 20`. Test in Task 5.
