# Handoff: Today redesign (2026-11-19)

Read this first when continuing on another machine. Nothing in the app has changed yet; this is design work only.

## Decided by the user
- **There is no brand yet.** The current look (Bricolage Grotesque headings, wine/maroon, "Board and Sheet", the register/ledger idea) is rejected. Bricolage feels cramped on phones. Do not preserve it or build on it. A brand gets set later, once students show they like a look.
- Students want **simple, uncongested** screens. The summary-tile idea was liked but felt basic.
- **Floating rounded tab bar** (Apple style) with tap effects: the active tab changes colour and shows its name, and the tab shrinks slightly on press. On laptop: a floating rounded sidebar.
- **Direction:** Daylight as the main (light) look, Night Focus as its dark mode. Colour Blocks is set aside.
  - Daylight changes still to make: replace the blue gradient "now" card with a **flat** card, and pick a **less default accent** than cobalt blue (used only for "now").
- The user worries the result will look AI-generated and basic. Answer this with product behaviour, not decoration (next section).
- Setup approach: "visible holes" (empty summary areas offer one-tap setup, no drip-fed setup cards). This still stands from the spec.

## Next task: second-version phone mockup (artifact, no app code)
Build Daylight (flat card, new accent) with a light/dark switch (dark = Night Focus) and these working:
1. **A smart line about the day** replacing the plain greeting, built only from data the app has: free gaps, late tasks, next class. Examples: "Free from 12 to 2. Enough time to finish the OS quiz, which is 2 days late." / "Lab at 2:00 PM. Leave in 10 minutes."
2. **"Can I skip this?"** on the class card: "Skip it and you're at 80%. Still safe. You'd have 2 left to spare." (The bunk maths already exists in the app, `onbShowBunk`.)
3. **Swipe the class card to mark it**, with the attendance ring moving 82% → 83%.
4. **Time-of-day versions** of Today: morning (plan), in class (almost empty), evening ("Mark today in one tap", tomorrow's dues), night (tomorrow's first class).
5. Student words: bunk, practicals, internals, End-Sem, ERP portal, 75% rule.
6. Remove the template signals: identical rounded cards everywhere, gradient hero, pulsing chip, corner avatar. Shape and size follow importance. A small custom icon set (6–8 icons).

After the user approves the mockup: rewrite `2026-11-19-today-glance-and-light-setup-design.md` for the new look, then build in small PRs (CLAUDE.md rules apply).

## Skills to use
- `ui-ux-pro-max` for design decisions and the checklist (contrast, 44px tap areas, colour never the only signal, one main action per screen).
- `ui-styling` for principles only (tokens, focus states, dark variants). The app is vanilla CSS with no build step; no shadcn/Tailwind, no new dependencies.
- `ui-council` to polish each built screen (one Sonnet reviewer, four lenses). It does polish only, not redesign.
